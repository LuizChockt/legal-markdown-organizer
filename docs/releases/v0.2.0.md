## Safe local history and undo

- Record real organization attempts in local JSON manifests with unique IDs,
  relative paths, SHA-256 hashes and verified file identities.
- List executions with `--history`; restore the latest pending execution with
  `--undo-last`; preview restoration with `--undo-last --dry-run`.
- Preserve existing commands, classification rules, filenames and document bytes.
- Refuse to overwrite originals or automatically restore changed, missing or
  replaced documents. Retry partial restores after resolving conflicts.
- Recover verified copy checkpoints after interruption. Keep ambiguous artifacts
  for manual inspection and preserve complete originals on copy/write failures.
- Add process locks, POSIX no-follow access and Windows reparse/junction checks.

Tested with fictional temporary documents. The release is published only after
the full GitHub Actions matrix succeeds on the exact main-branch commit: Python
3.11/3.14 on Linux, Windows and macOS, plus Python 3.12/3.13 on Linux. Each job also
builds, installs and exercises the wheel outside the checkout.

Python 3.11+; no runtime dependencies. Install the attached wheel with
`python -m pip install --upgrade ./legal_markdown_organizer-0.2.0-py3-none-any.whl`,
or use the source checkout. No PyPI publication is implied.

Undo is not a backup. Close editors/sync clients, keep normal backups and preview
both organization and restoration. Empty category folders remain. See
[`docs/history.md`](https://github.com/LuizChockt/legal-markdown-organizer/blob/v0.2.0/docs/history.md)
for format, recovery procedures and filesystem limits.
